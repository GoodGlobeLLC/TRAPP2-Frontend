Growth & Inflation Regime Detection

    
A four-quadrant macro framework based on the rate of change of growth and inflation. Each regime has historically favored different sectors, asset classes, and investment styles.

    

      This is a transparent, public-data approximation using FRED's official Real GDP (GDPC1) and CPI (CPIAUCSL) series — not Hedgeye's proprietary GIP nowcast. No API key needed for macro data. Use this as an educational reference; their daily Quad call is a paid service with proprietary inputs.

Binary Thesis Odds · prediction-market style

    

      Each thesis is a yes/no question — "AAPL above $250 by Aug 1". Probability is blended
      from four inputs: historical (log-normal fit of your sheet's price history),
      valuation (DCF margin of safety), macro (current Quad's sector
      bias), and your manual prior. Adjust the weight slider on each thesis to see
      how much each factor matters.

Scenario Lab

      
Macro shocks · transmission channels · ranged impact estimates · all outputs tagged by epistemic tier

    

    

      
      
      
    

  


  
  

    

      Define Shocks
      Each shock has a magnitude and a confidence-in-the-shock-itself. The engine treats these as independent inputs (no implicit correlation assumed).
    

    

      
    

    

      

        Honest defaults:
        Elasticity ranges come from peer-reviewed studies (Hamilton 2003 oil-GDP, Bernanke/Gertler/Watson 1997 oil-equity, Edelstein/Kilian 2009 oil pass-through, etc.).
        Specific numbers are presented as ranges (e.g. ±2σ on the elasticity), not points.
        The engine does not claim "this will be like 1973 or 1990 or 2022" — it cites those episodes only to disclose where its parameter ranges come from.
      

    

  


  
  

    

      Timeline Horizons
      Different transmission channels resolve at different speeds. Energy-cost pass-through hits margins in 1-2 quarters; demand destruction takes a year+; capex reallocation takes 2-5 years.

Active Source Preference

      

        
        
        
        
      

      
Auto = blend all sources, GitHub raw URL wins for prices/history. GitHub First = always prefer GitHub URLs over Google Sheets. Sheet First = prefer your sheet values.

    


    

      
Data Source URLs (one per line — Google Sheets URLs AND/OR raw GitHub URLs)

      
      

        Google Sheets: File → Share → Publish to web → choose sheet → CSV → Publish. Paste the URL.

        GitHub: Paste raw URLs directly — supported files:

          • master.csv or master.json — quotes & fundamentals

          • history_manifest.json — auto-loads all per-ticker 5y history files

          • prices.json — combined history (alternate format)

          • history/AAPL.json — single ticker history (one URL each)

        All URLs merged. Use Active Source Preference to control which wins for duplicate fields.
